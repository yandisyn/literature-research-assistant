# Methods and observed results

## Validation scope

| Input | Size | Exercised workflow | Boundary |
|---|---|---|---|
| First-page PDFs | 32 papers | Visible metadata and structured records | Not full-text review |
| Full PDF | One 16-page paper | Full-text extraction and reading notes | Not every figure/table visually verified |
| Zotero | 223 attachments, 213 screened records | Metadata matching, caching, duplicates, candidate topics | Not 213 full-text reviews |
| WoS | 242 papers, 2022–2024 | Co-citation, bursts, figures, workbook | Not a complete field or confirmed frontier |

Zotero screening used 70 library abstracts, 97 PDF abstract candidates, and 46 titles only. One record had no usable English features. The library changed during the run; 223 is the final attachment snapshot. Metadata came from an authorized read-only database backup, not a live API snapshot.

## Co-citation

Annual sample sizes were 64, 83, and 95; the export date was 2024-10-23, so the final year is incomplete. There were 16,089 raw reference occurrences and 11,329 normalized keys, including 54 unresolved multi-DOI keys.

Single unambiguous DOI strings identify references; other strings receive conservative normalization with raw variants retained. No online DOI validation or complete identity disambiguation was performed. Each citing paper counts once per reference.

Co-citation frequency counts papers citing both references. Cosine weight is `c(a,b)/sqrt(c(a)*c(b))`. The top 80 references cited by at least three sample papers were selected, retaining pairs co-cited at least three times. Seeded Louvain clustering (seed 42) on 1,501 weighted edges produced three clusters, Q≈0.176. Plotting retains 183 edges from top-three neighbors and a maximum spanning forest; clustering uses the full analysis graph.

## Bursts and frontier candidates

Annual reference counts are normalized by annual sample size. Detection uses a two-state binomial adaptation of Kleinberg. Strength is the emission log-likelihood gain over baseline, not a p-value or a CiteSpace-equivalent score. Minimum duration filters fitted intervals rather than refitting a duration-constrained model.

| Gamma | Minimum years | References with bursts |
|---|---|---|
| 0.5 | 1 | 169 |
| 0.5 | 2 | 3 |
| 1 | 1 | 38 |
| 1 | 2 | 0 |
| 2 | 1 | 0 |
| 2 | 2 | 0 |

s=2 throughout. All 38 default intervals last one year; 18 touch the final year and are exported as candidates requiring reading. Boundary censoring, the short window, incomplete final-year coverage, and parameter sensitivity preclude a stable-frontier claim.

## Reproducibility

Five algorithm tests cover DOI ambiguity, constant proportions, a simulated peak, dynamic programming versus exhaustive search, and two WoS formats. The actual run checked support sets for all 11,329 references and 1,501 edges, including cosine weights and an unchanged source hash. Workbook row counts and absence of error cells were checked, and figure/sheet previews inspected.

Run `python literature-review-map/scripts/test_wos.py` to repeat the algorithm tests. Original datasets are not distributed, so these example figures cannot be regenerated from the repository alone. Run the pipeline on your own authorized data and retain parameters and source hashes.
