# Release notes

Repository: https://github.com/yandisyn/literature-research-assistant-

This initial package contains the six-module skill suite, English documentation, executable helpers, and four derived PNG examples. It excludes original PDFs, Zotero databases, full-text caches, complete WoS records, host dependencies, and local reports containing personal paths.

The project uses the MIT License selected by the repository owner. Dataset and third-party publication rights are not transferred by this repository.

The analysis was tested primarily on Windows with existing runtimes. Fresh-environment installation and end-to-end execution on macOS/Linux remain unverified. The optional Excel dependency is host-provided; CSV remains available without it.

Before subsequent releases, run the algorithm tests, validate skill metadata and Markdown links, inspect generated figures, and verify that no private source data or credentials are included.
