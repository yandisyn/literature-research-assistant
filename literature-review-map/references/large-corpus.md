# Low-token corpus screening

Use this mode when the user requests economical exploration of a large PDF collection. It is a separate screening tier, not full-text semantic review.

1. Cache all PDF text locally with ingest.py. Use `--backend pdfium` if pypdf is slow; unchanged content-addressed caches are reused. Partial progress is saved in manifest.partial.json. A successful extraction says nothing about semantic reading completeness.
2. Prefer available Zotero metadata. If the local API is unavailable, access a database only with authorization. Use `zotero_metadata.py --database PATH --storage PATH --output PATH`. It uses SQLite read-only mode and integrity checking. Do not kill Zotero or bypass a database lock. An available backup may be used with its snapshot date prominently disclosed; check attachment coverage.
3. Run `benchmark_corpus.py --output PATH` in an environment containing numpy, scipy, scikit-learn, networkx and matplotlib. It uses SHA-256 duplicate detection, attachment grouping, supplemental-material screening, title/abstract TF-IDF, eight exploratory NMF topics, phrase co-occurrence and static figures. English-only feature extraction leaves zero-feature documents unclassified. This baseline is domain-neutral but not a validated topic model; inspect representative documents and adjust scope before publication.
4. Inspect representative records from each topic, ambiguous metadata, missing abstracts and sparse-text files. Pay attention to publisher/ResearchGate cover pages, preprint versus published versions and supplementary PDFs. Version-specific corrections go into audit-overrides.json with page evidence; never modify Zotero automatically.
5. `screening-records.json` is automated screening output, distinct from the fully curated schema. Do not populate full-text findings or author affiliations by guessing. Authors and years from Zotero remain metadata, not verified identities. Phrase co-occurrence is not author-keyword co-occurrence. NMF topics are not human-validated research themes or citation bursts.
6. Run `refine_maps.py --output PATH` for curved network edges, transparent cluster envelopes, label collision avoidance and thematic trajectories. It preserves the network, separates disconnected components for layout, and uses descriptive temporal connections rather than inventing citation links. Inspect images at readable size; no publication-readiness claim follows merely from 450 DPI.
7. Review source hashes at completion. If the live storage changes, rescan from cache and report the final snapshot. Check counts, exclusions, edge-support lists and figure readability. Record limitations instead of inventing an extraction accuracy rate from a small convenience sample. Reject HTML pages saved with a .pdf suffix; do not call them scanned PDFs.

The screening outputs retain all structured records locally; send only aggregate reports, selected page excerpts and doubtful fields into model context. Do not claim a measured token-saving percentage without actual usage measurements.
